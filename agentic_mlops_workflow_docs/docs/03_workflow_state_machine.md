# Workflow State Machine

## Идея

Workflow должен быть state machine. Это делает процесс понятным, тестируемым и аудируемым.

## Основные состояния

```text
NEW_DATASET
DATA_INTAKE_RUNNING
DATA_INTAKE_FAILED
DATA_INTAKE_NEEDS_HUMAN_APPROVAL
DATASET_STRUCTURING_RUNNING
DATASET_VALIDATION_RUNNING
DATASET_VALIDATION_FAILED
DATASET_NEEDS_CLEANUP
NEEDS_LABELING
PSEUDOLABELING_RUNNING
LABEL_REVIEW_REQUIRED
LABEL_QA_RUNNING
LABEL_QA_FAILED
DATASET_READY_FOR_VERSIONING
DATASET_VERSION_REGISTERED
TRAINING_APPROVAL_REQUIRED
TRAINING_RUNNING
TRAINING_FAILED
EVALUATION_RUNNING
EVALUATION_FAILED
MODEL_DECISION_RUNNING
MODEL_APPROVAL_REQUIRED
MODEL_REJECTED
MODEL_APPROVED
MODEL_REGISTERED
DEPLOYMENT_APPROVAL_REQUIRED
DEPLOYMENT_RUNNING
DEPLOYED_TO_STAGING
DEPLOYED_TO_PRODUCTION
MONITORING
RETRAINING_REQUIRED
COMPLETED
CANCELLED
```

## Основной happy path

```text
NEW_DATASET
 → DATA_INTAKE_RUNNING
 → DATASET_STRUCTURING_RUNNING
 → DATASET_VALIDATION_RUNNING
 → NEEDS_LABELING
 → PSEUDOLABELING_RUNNING
 → LABEL_REVIEW_REQUIRED
 → LABEL_QA_RUNNING
 → DATASET_READY_FOR_VERSIONING
 → DATASET_VERSION_REGISTERED
 → TRAINING_APPROVAL_REQUIRED
 → TRAINING_RUNNING
 → EVALUATION_RUNNING
 → MODEL_DECISION_RUNNING
 → MODEL_APPROVAL_REQUIRED
 → MODEL_APPROVED
 → MODEL_REGISTERED
 → DEPLOYMENT_APPROVAL_REQUIRED
 → DEPLOYED_TO_PRODUCTION
 → MONITORING
```

## Важные transitions

```yaml
transitions:
  DATASET_VALIDATION_RUNNING:
    success: DATASET_READY_FOR_VERSIONING
    failed: DATASET_NEEDS_CLEANUP
    needs_labeling: NEEDS_LABELING

  LABEL_QA_RUNNING:
    success: DATASET_READY_FOR_VERSIONING
    suspicious_labels: LABEL_REVIEW_REQUIRED
    failed: LABEL_QA_FAILED

  TRAINING_RUNNING:
    success: EVALUATION_RUNNING
    failed: TRAINING_FAILED

  MODEL_DECISION_RUNNING:
    promote_candidate: MODEL_APPROVAL_REQUIRED
    reject: MODEL_REJECTED
    retrain: TRAINING_APPROVAL_REQUIRED
    need_more_data: NEW_DATASET
    need_label_review: LABEL_REVIEW_REQUIRED

  MONITORING:
    stable: MONITORING
    drift_detected: RETRAINING_REQUIRED
    hard_samples_detected: NEW_DATASET
```

## Human approval states

Human approval states должны блокировать автоматическое продолжение workflow:

```text
DATA_INTAKE_NEEDS_HUMAN_APPROVAL
TRAINING_APPROVAL_REQUIRED
MODEL_APPROVAL_REQUIRED
DEPLOYMENT_APPROVAL_REQUIRED
```

## Audit log

Каждый transition должен писать audit event:

```json
{
  "workflow_id": "wf_2026_06_12_001",
  "from_state": "MODEL_DECISION_RUNNING",
  "to_state": "MODEL_APPROVAL_REQUIRED",
  "actor": "model_decision_agent",
  "reason": "All metrics passed policy. Human approval required.",
  "timestamp": "2026-06-12T10:30:00Z",
  "artifacts": ["evaluation_report.json", "decision_report.md"]
}
```
